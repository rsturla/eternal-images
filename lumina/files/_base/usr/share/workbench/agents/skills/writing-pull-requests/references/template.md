# Pull request template

Copy this template. Fill each section. Delete a section only when it does not
apply. Keep the template short so writers use it.

```markdown
## Why

<!-- The problem or the goal. One or two sentences. Not only a ticket link. -->

## What

<!-- The main changes, as bullets. -->
-
-

## How to test

<!-- The exact steps, commands, or checks the reviewer runs. -->
1.
2.

## Risks and follow-ups

<!-- Breaking changes, migrations, config changes, or later work. Write
"None" if there are none. -->

## Links

<!-- Related issues or documents. Example: Closes #123. -->
```

## Repository template

To make this the default for a repository, save it as
`.github/PULL_REQUEST_TEMPLATE.md`. The host then fills the body for each new
pull request. Keep the repository template lean, with four to six prompts. A
long form with many checkboxes gets ignored.
