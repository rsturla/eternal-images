# Word choice

STE uses a dictionary of about 900 approved words. Each word has one part of
speech and one approved meaning. The full dictionary is a proprietary part of
the standard. This file explains the method and gives common examples. For the
authoritative word list, see https://asd-ste100.org.

## Method

- Use one word for one meaning. Do not use a synonym for a word you already use.
- Use the shorter, more common word.
- Use a word only in its approved part of speech. For example, use "test" as a
  noun and "do a test" for the action, if "test" is not approved as a verb in
  your context.
- Keep a technical name or a technical verb when no approved word fits. Define
  it once.
- Do not use a word that has more than one meaning if a clearer word exists.

## Common substitutions

Use the approved word on the left. Avoid the words on the right.

| Use | Do not use |
| --- | --- |
| start | begin, commence, initiate |
| use | utilize, employ, leverage |
| make sure | ensure, verify that (as a synonym) |
| about | approximately, roughly, around |
| before | prior to, in advance of |
| after | subsequent to, following |
| help | assist, aid, facilitate |
| enough | sufficient, adequate |
| find | locate |
| let | permit, allow |
| get | obtain, acquire |
| show | display, indicate, illustrate |
| tell | inform, advise, notify |
| but | however, nevertheless |
| so | therefore, thus, hence |
| about (a topic) | regarding, concerning, with respect to |
| do again | (rewrite; avoid "reiterate") |

## Words to avoid in agent text

- Avoid hedging words: "should", "might", "could", "generally", "usually",
  "typically". A reader treats "should" as optional.
- Avoid filler: "just", "simply", "basically", "actually", "in order to" (use
  "to").
- Avoid vague quantity words: "some", "several", "a few". State a number.
