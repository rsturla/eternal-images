# STE compliance checklist

Check the text against each item. Fix a problem, then check again. Stop when
the text meets all items or when a fix would change the meaning.

## Sentences

- [ ] Each procedure sentence has 20 words or fewer.
- [ ] Each descriptive sentence has 25 words or fewer.
- [ ] Each sentence has one idea.
- [ ] Each procedure sentence has one instruction.
- [ ] No sentence drops an article or another word that aids clarity.

## Verbs and voice

- [ ] The text uses the active voice. Procedures have no passive voice.
- [ ] The text uses only simple tenses (imperative, present, past, future).
- [ ] No `-ing` form is used as a verb.
- [ ] No instruction uses "shall" or "should". Instructions use the imperative.

## Words

- [ ] The text uses approved words. See [word-choice.md](word-choice.md).
- [ ] Each word has one meaning in the text.
- [ ] The text uses the same term for the same thing each time.
- [ ] No noun cluster has more than three nouns.
- [ ] No slang, idiom, or hedging word ("might", "generally", "usually").

## Structure

- [ ] A condition or a purpose comes before its instruction.
- [ ] A warning or a caution comes before the step it applies to.
- [ ] Complex or sequential information uses a vertical list.
- [ ] Each paragraph keeps to one topic and six sentences or fewer.

## Common mistakes

- A long sentence with two instructions joined by "and". Split it.
- The passive voice in a procedure. Rewrite with an imperative verb.
- A synonym used for variety. Use the same word each time.
- A hedging word that makes a rule optional. State the rule directly.
- A dropped article that saves one word but adds doubt. Keep the article.
